# Job Preparation Tracker with Insights

## Overview
Job Preparation Tracker is a web-based platform designed to help students prepare for placements by providing access to senior placement profiles, skill-gap insights, and placement analytics.

## Problem Statement
Students often lack a clear understanding of the skills required for placement opportunities and the experiences of seniors who have successfully secured jobs. This platform aims to make placement-related information easier to access and understand.

## Key Features
- **Student Authentication:** Student registration and login.
- **Student Dashboard:** Access placement-related information.
- **Senior Profile Search:** Search and filter senior profiles based on relevant details.
- **Skill Matching:** Compare student skills with the skills listed in senior profiles and identify missing topics.
- **Placement Analytics:** View company-wise placement information, salary insights, and hiring trends through interactive charts.
- **Admin Features:** Manage placement-related records.

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Chart.js

## Project Structure
The project contains the frontend files, Firebase configuration, authentication modules, student and admin features, and analytics functionality.

## Getting Started
1. Clone this repository.
2. Open the project folder.
3. Configure Firebase Authentication and Cloud Firestore using your own Firebase project credentials.
4. Run the application using a local development server.
